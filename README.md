# Grow Castle Calculator Android — v1.1
Target game version: Grow Castle 1.50.14.

Features:
- Push Wave, Colony, Dungeon, Skill Point, Towers, Database
- Builds: Lightning, Physical, Fire, Ice, Poison, Summon, Gold/Farming, Custom
- Offline calculator
- Current 1.50.x changes represented: Thorn Worm promotion, Bazooka/Cannoneer promotion changes, tower item support, Town Archer item-stat changes, Devil's Horn +5.
- Hero/tower names are stored in the Android source database and ratios are editable in source.

Important accuracy note:
Grow Castle does not publish a complete official public table of recommended hero/tower-to-wave ratios. Therefore ratios such as 0.10 Town Archer, 0.04 damage dealers and 0.02 support are community/planner recommendations, not official formulas. The app labels them accordingly.

Build APK:
1. Open this project in Android Studio.
2. Sync Gradle.
3. Build > Build APK(s).
4. Install app/build/outputs/apk/debug/app-debug.apk on Android.
